Overview

Robust segmentation under weak semantics and unstable temporal context.

Video polyp segmentation is challenging because polyps often resemble surrounding mucosa, while motion blur and scale changes make temporal propagation unreliable. CMSA-Net addresses these issues by combining causal temporal modeling with adaptive reference selection.

The framework introduces a Causal Multi-scale Aggregation module to gather features from historical frames at multiple scales, and a Dynamic Multi-source Reference strategy to adaptively select reliable reference frames. On SUN-SEG, CMSA-Net achieves state-of-the-art performance while retaining practical efficiency for clinical video workflows.

Method

Causal temporal aggregation with adaptive reference memory.

CMSA-Net uses temporal causality to avoid future-frame leakage and combines long-term, semantic, and local references for stable per-frame prediction.

Visual results

Cleaner masks across hard video frames.

Qualitative comparisons show that CMSA-Net maintains more complete polyp masks than baseline predictions under ambiguity, blur, and appearance variation.
